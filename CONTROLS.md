# Controls

All bindings are active simultaneously. Options > Game > Controls displays this read-only combat reference in both title and pause menus.

| Action | Keyboard / mouse | Controller (Xbox / PlayStation) |
|---|---|---|
| Move | WASD or arrows | Left stick or D-pad |
| Attack / hold to spin | J, Z, left mouse | X / Square |
| Jump | K, X, Space | A / Cross |
| Magic | L, C, right mouse | Y / Triangle |
| Run | Shift; horizontal double tap retained | RB / R1; horizontal double tap retained |
| Pause | Escape | Start / Options |
| Menu confirm | Enter / Space | A / Cross |
| Menu back | Escape | B / Circle |
| Fullscreen | Alt+Enter | Display options |

Charge uses run + attack. Jump attack uses jump then attack. No combat behavior changes. Q still cycles weapons as an existing shortcut.

Multiple physical controls merge into a single logical action. Releasing one attack binding while another remains held does not reset the spin hold. Left stick has a 0.35 gameplay dead zone; digital movement retains existing movement speeds. Disconnecting a controller clears held inputs and pauses combat. Controls uses the Cinzel HUD font, a responsive combat table, white controller glyphs and the shared stone Back button. Narrow windows stack bindings per action; short windows scroll with the mouse wheel, W/S, arrow keys, D-pad or stick. Menus support W/S and up/down for navigation, A/D and left/right for adjustable values, and Enter/Space to confirm. Remapping is not yet provided.
