Stone & Bronze

A smaller original Cairn logo over a full-width, firelit stone war hall, fading into the continuous stone background below. A translucent charcoal panel and bronze native button complete the page. Built around the standard itch.io theme editor.

No custom CSS access required. The preview stylesheet recreates itch.io’s surrounding layout locally; it is not a stylesheet to paste into itch.io.

Content to upload

  1. Create or edit the game page. Keep it in draft while setting up.
  2. Paste the description using the description editor’s HTML view. It contains only headings, paragraphs, a list, emphasis, and line breaks.
  3. In Edit Theme, set the values above. The banner replaces the default text title.
  4. Upload aqueduct.jpg, foundry.jpg, and keep.jpg as screenshots.
  5. When approved for release, upload the trailer to a supported video host and add its public URL to the trailer field. The local MP4 player is a stand-in for that embed.
  6. Set pricing, release status, downloads, cover image, credits, and system requirements separately. These are intentionally not invented by this study.

What is real / what is simulated

The official CSS guide documents a 960px content column and 553px description area. This study follows those dimensions on desktop. Surrounding navigation, gutter spacing, purchase UI, video controls, and mobile stacking are approximations; the live editor is the final authority.

The top review toolbar is local only. The download button cannot buy or download anything. Browser mode adds a 16:9 click-to-play placement above the description, while retaining Sidebar explicitly. Its Run game button opens the existing local game server on port 3001, if running.

The actual itch.io game embed must be configured separately: the project must be an HTML5 game with its web build uploaded. Native downloads do not produce an embedded game automatically.

The banner assembles the original logo at 43% of the image width over generated scenery. Top and sides fill the banner edge to edge. Only the jagged lower stone edge reveals the page texture; the bottom edge is fully transparent. The artwork requires no CSS fade or special header background. The background also extends outside the panel. The three screenshots are unretouched frames from the existing staged native-game trailer; they depict actual engine combat, but are not fresh captures of the latest build.

Platform limits

The native button keeps its standard shape; only its color changes. Textured or beveled buttons would require custom CSS and are not part of this concept.

Standard controls support colors, fonts, banner and background images, and Sidebar / Hidden / Auto layouts. Custom CSS requires approval per account. If added later, keep changes within #wrapper, retain itch.io’s UI and footer links, and prefix description classes with custom-. JavaScript and this complete preview HTML are not a deployable itch.io theme.
