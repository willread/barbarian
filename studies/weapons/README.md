# Cairn weapon concepts — first pass

Design exploration only. No gameplay, unlocks, statistics, or weapon assets have been changed.

All concepts use a rigid weapon sprite with a straight grip axis and a fixed hand pivot, matching the current attachment system. Swords retain longer silhouettes; axe and blunt heads stay compact enough for spins and descending strikes. Actual grip positions, handedness, hitboxes, and ground-contact placement need verification after selection. Maces and hammers can reuse the body motion but need dedicated impact tuning and audio; these are not drop-in sword reskins.
